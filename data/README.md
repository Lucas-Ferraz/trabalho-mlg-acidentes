# Instruções para Obtenção dos Dados

Para reproduzir as análises:
1. Baixe o conjunto de dados oficiais da PRF no portal [Dados Abertos da PRF](https://www.gov.br/prf/pt-br/acesso-a-informacao/dados-abertos/dados-abertos-da-prf).
2. Faça o download dos arquivos `datatran2024.zip` e `datatran2025.zip`.
3. Extraia os arquivos `datatran2024.csv` e `datatran2025.csv` e salve-os nesta pasta (`data/raw/`).
