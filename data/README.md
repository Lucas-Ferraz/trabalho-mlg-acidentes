# Instruções para Obtenção dos Dados

Para reproduzir as análises:
1. Acesse o portal de [Dados Abertos da PRF](https://www.gov.br/prf/pt-br/acesso-a-informacao/dados-abertos/dados-abertos-da-prf).
2. Localize as opções do tipo **(Agrupados por ocorrência)** para os anos de 2024 e 2025.
3. Clique em **"Baixar planilha"** ao lado de cada uma para fazer o download dos arquivos `datatran2024.zip` e `datatran2025.zip`.
4. Extraia os arquivos `datatran2024.csv` e `datatran2025.csv` e salve-os nesta pasta (`data/raw/`).
